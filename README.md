# KitsuneLoc — інструментарій перекладу Crystar / Mary Skelter: Nightmares

```
trans/
  translate_msk.py        CLI для Mary Skelter
  translate_crystar.py    CLI для Crystar
  common.py               спільний формат JSON-файлів перекладу
  Переклад.pyw            вікно з кнопками — основний спосіб роботи
  sheets.py               JSON <-> книги Excel
  maryskelter/            парсери Mary Skelter: bra.py (PDA-архів), gbnl.py (GBIN/GSTR), cl3.py
  crystar/                парсер Crystar: unitystr.py (рядки в Unity MonoBehaviour)
  work/                   тут з'являться JSON-и з текстом (створиться сам)
  out/                    тут з'являться пропатчені файли (створиться сам)
```

Залежності: Python 3.8+. Для Crystar додатково `pip install UnityPy`.
Для Mary Skelter нічого ставити не треба — лише стандартна бібліотека.

## Mary Skelter: Nightmares

```cmd
python translate_msk.py export %MSK% work\msk
python translate_msk.py import %MSK% work\msk out\msk
```

* Діалоги лежать у `Script.bra` **двічі**: `_EN\EVENT\DATA` і `EVENT\DATA`.
  Обидва дерева англійські (японського тексту у Steam-версії немає), 27 310 з
  27 312 рядків ідентичні, різняться нетекстові поля записів. Експортується
  `_EN`; імпорт пише переклад **в обидва** дерева (у дзеркальне — лише там, де
  оригінал за тим самим id збігається).
* Кодування визначається для кожного файлу: діалоги в UTF-8, решта — Shift-JIS.
  Для Shift-JIS `і/І` автоматично замінюються на латинські `i/I` (виглядають
  однаково), `ї є ґ` у Shift-JIS немає — такі рядки пропускаються з
  попередженням.
* GBIN/GSTR у big-endian підтримуються.
* `Game.bra\StringData`, `Game.bra\DATABASE` — **залишки з Monster Monpiece**
  (рядки «モンスターモンピース», карткові бої), грою не використовуються.
* **Інтерфейс** — `TTM1.bra`: `Text\TextData.bin` (системні повідомлення,
  1 143 записи) і `Text\TextDataEx.bin` (екран статусу, 911) — **підтримуються**
  (`maryskelter/textdata.py`, перезбирання байт у байт). Формат: `u32 count`,
  12 нулів, `count × {u32 offset, 12 нулів}`, пул NUL-рядків UTF-8 (порожній
  рядок займає `\0\0`), хвіст. `#n` — перенос (у книзі показується як `\n`),
  `#I`/`#F` і printf-формати перевіряються `validate()`.
* **Таблиці** `TTM1.bra\data\table.enc` (предмети, спорядження, навички…) і
  `DLC.bra\DLCINFO\*.enc` (описи DLC) — **підтримуються** (`enc.py`, `table.py`).
  Контейнер: `u32 count`, `count × {u32 stored|0x80000000=стиснено, u32 raw_size,
  u32 offset}`, секції стиснені LZO1X-1 (`lzo1x.py`); змінені пишуться
  нестиснутими. Рядки — слоти фіксованої місткості.
  У `DLC.bra` діалогів немає — лише CG (`EVENT\STILL`).
* **Японська версія** (`maryskelter/cpk.py`: CRI CPK + CRILAYLA). Діалоги —
  `SCRIPT.cpk/EVENT/DATA/*.gbin` (UTF-8): 439 з 440 сцен мають **ту саму
  структуру**, що й `_EN`, тож пари беруться за (запис, поле) — колонка «Японська»
  в книгах сюжету й «Імена». Бракує `210054`. `SCRIPT.cpk` шукається в
  `trans/maryskelter/`, у `--jp` або в теці гри.
  Інтерфейс (`TTM.cpk/Text/TextData.bin`, 1 131 запис проти 1 143) між версіями
  переставлено — надійно зіставляється лише ~840 рядків, тому японська колонка
  для інтерфейсу **свідомо не додається**. `GAME.cpk`/`SYSTEM.cpk` японського
  тексту гри не містять (залишки Monster Monpiece, шрифти, звук; японський
  `msgfont.ffu` — 9,1 МБ проти 23,8 МБ англійського).
  `python translate_msk.py cpk <file.cpk> [--out ТЕКА] [--only ФРАГМЕНТ]`.
* Імена мовців — окрема книга «Імена» на всю гру. Кожен запис репліки має ще й
  числовий id персонажа (зсув 4: Jack=0, Alice=100, Red Riding Hood=200…), але
  імена більше ніде текстом не лежать, тож табличку, найпевніше, малює поле 368.

## Crystar

```cmd
python translate_crystar.py export %CRY% work\crystar
python translate_crystar.py import %CRY% work\crystar out\crystar --slot en
python translate_crystar.py import %CRY% work\crystar out\crystar --slot ja
```

* Кожна таблиця/сцена є в 4 мовних копіях (`_ja _en _ko _zhtw`), а кожна сцена —
  ще й у двох бандлах озвучки (`ev_XXXXXX_en`, `ev_XXXXXX_ja`), текст у яких
  ідентичний (перевірено на всіх 420 сценах).
* Експорт зводить усе в **один** JSON на сцену/таблицю з англійським (`src`)
  і японським (`ja`) оригіналом. Мови зіставляються за порядковим номером
  рядка — кількість і структура копій однакові (365 сцен, 10 таблиць). За
  ключами зіставляти не можна: в `ev_122025` англ. копія має чужий ключ.
* Імпорт пише переклад у вибраний слот (`--slot en|ja`) у **всі** бандли сцени.
  У грі має стояти та сама мова тексту.
* Мовець (`EV_CHARA_0026`) підставляється іменем з `ScriptableCharacterMessage`.
* Теги (`crystar/tags.py`): змінні `<CHARA|WORD|SYS=KEY>` (усі 261 ключ є в
  `parameter`, можливе вкладення), плейсхолдери `<ITEM> <VALUE> <SKILL> <TIME>
  <TYPE> <CHARA>`, `<ICON=…> <BUTTON=…>`, колір `<#RRGGBB>…</color>`. У книзі
  японська колонка показується з розшифрованими змінними (`〔零〕`), англійська —
  сирою; колонка «Підказка» пояснює теги рядка. `validate()` ловить загублені
  технічні теги, невідомі ключі й зламані `<`/`>`.

## Розкладка по книгах

Книга = розділ, за шаблоном шляху сцени (`sheets.DEFAULT_BOOKS`). Crystar:
`ev_1N…` — пролог (N=0), розділи 1–7 (N=1…7), фінальний (N=8); `ev_2/3/4…` —
повторні проходи; `ev_calling…`, `ev_chara/npc/shop`. Mary Skelter: сюжет
`00GGxx` за сотнями (GG = 00…11, 04 і 06 відсутні), `10xxxx`/`20xxxx` —
додаткові сцени, `21xxxx` — короткі репліки. Відповідність груп розділам гри —
гіпотеза за номерами; назви перевизначаються файлом `розділи.json`
(шаблон — `розділи.приклад.json`). Книги, яких розкладка більше не створює,
переносяться в `Переклад/<гра>/_старі книги/<час>/`. Якщо один рядок є в кількох
книгах, заповнене перемагає порожнє.

## Формат файлів перекладу

Кожен вихідний файл → свій `.json` за тим самим шляхом і назвою, тому імпорт
знаходить пару автоматично:

```
work\msk\Script.bra\_EN\EVENT\DATA\000001.gbin.json
work\crystar\parameter\Game.ScriptableSystemMessage_en.json
work\crystar\Event\ev_101010_en\ev_101010_msg_en.json
```

```json
{"game":"msk","source":"Script.bra/_EN/EVENT/DATA/000001.gbin","format":"gbin",
 "entries":[{"id":"0:368","src":"Jack","tr":""}]}
```

`tr` порожній → береться оригінал. Повторний `export` **не затирає** переклад:
оновлює `src`, лишає `tr` за тим самим `id`.

## Формати (реверс)

### PDA / `.bra` — `maryskelter/bra.py`

```
header 16 B: 'PDA\0', u32 version=2, u32 index_offset, u32 file_count
blob:  u32 raw_size, u32 comp_size, u32 crc32(raw), u16 method=6, u16 flags
       + raw deflate           (stored = 16 + comp)
index: u32 mtime, u32 crc32, u32 stored, u32 raw_size,
       u16 name_len (вирівняно до 4), u16 0x20, u32 blob_offset, name
```

Перевірено: `System.bra` і `Script.bra` перезбираються **байт у байт**.

### GBIN / GSTR — `maryskelter/gbnl.py`

Дескриптор 0x40 байтів (у GBIN футер, у GSTR хедер) → таблиця типів полів →
масив записів → пул рядків. Поле типу 5 = зміщення в пулі, `0xffffffff` = немає.
Пул перебудовується з дедуплікацією, перезбирання теж байт-у-байт.

### CL3 — `maryskelter/cl3.py`

`FILE_COLLECTION` + `FILE_LINK`. Читання/перезбирання байт-у-байт. Знадобиться,
тільки якщо доберемося до STCM2L.

### Unity MonoBehaviour — `crystar/unitystr.py`

Гра на IL2CPP, type tree недоступний. Сканер іде по сирих даних об'єкта і
знаходить поля `u32 length + UTF-8 + padding до 4`. Абсолютних зміщень
усередині ScriptableObject немає, тож рядок можна замінити на довший/коротший.

### Написи на картинках — `maryskelter/{ti,dds,atlas}.py`, `атлас/`

Атласи інтерфейсу — CL3 з парою `*.TI` (нарізка кадрів, `ti.py`) і `*.tid`
(DDS DX10 BC7). Гра приймає **лише BC7**: нестиснутий B8G8R8A8 дає чорний
екран. `dds.py` перекодовує (etcpak) тільки блоки 4x4 під зміненими
кадрами — решта файлу лишається байт-у-байт оригінальною.

`атлас/написи.json` — розмітка: для кожного атласу кадри з текстом, стилем,
способом стирання (`рядки`, `прозорий`, `шаблон`, `картинка`, `смуги`,
`стрічка`, `похила`), областю старого напису, висотою літер і полем для
нового. `атлас/стилі.json` — пресети (шрифт з `атлас/шрифти/`, заливка чи
градієнт, обведення, тінь, сяйво, нахил, поворот). Кегль підбирається сам —
під висоту літер оригіналу; задовгий переклад стискається до 85% і лише тоді
зменшується. `атлас/розмітка.py` — інструмент для розмітки (огляд сітки,
додавання кадрів, аркуш перевірки, контроль меж). `atlas_editor.py` — вікно
перекладу з живим прев'ю.

Експорт: один документ `@атлас/написи` (рядок на унікальний англійський
напис) → книга «24 Написи на картинках» з прев'ю спрайтів. Імпорт
перемальовує атласи з чистих оригіналів і кладе їх у той самий прохід
перепакування `TTM1.bra` / `DLC.bra`; `TTM3.bra` перепаковується окремо.

## Що лишилось

1. **Шрифти.** Mary Skelter — зроблено (`ffu.py`, `fontfix.py`, `chars.py`,
   плюс патч відступів у `патч\`). Crystar — шрифти в `static`/`uistatic`,
   треба глянути окремо.
2. **Переноси.** У `.gbin` вони жорстко зашиті як `\n`, довші українські рядки
   доведеться ламати вручну.
3. **STCM2L** (`main.CL3`) — тексту немає, але є логіка вибору реплік.
